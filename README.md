# 🧠 Kislay Tinker — Personal Portfolio Website

A clean, responsive personal portfolio website built with HTML, CSS, and JavaScript — showcasing my skills, projects, certifications, and experience in Data Science, Machine Learning, and NLP.

🌐 **Live Site:** [kislaytinker.github.io/Personal-Portfolio](https://kislaytinker.github.io/Personal-Portfolio)

---

## 📌 Sections

- **About** — Introduction, services, certifications, and tech stack
- **Resume** — Education, experience, certifications, leadership, and skills
- **Portfolio** — Projects filterable by category (ML/AI, NLP, Systems, Data Analytics)
- **Contact** — Contact form powered by Formspree + Jaipur map

---

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| HTML5 | Structure |
| CSS3 | Styling & animations |
| JavaScript | Interactivity & filtering |
| GitHub Pages | Deployment |
